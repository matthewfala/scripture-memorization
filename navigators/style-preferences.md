# Style Preferences

Living constraints on musical style, learned from memorization experience.
Procedure 00 (style partition) must read this file before assigning any
style. Update this file whenever listening feedback teaches something new,
then re-run Procedure 00 (LOCKED and ACCEPTED packets are never altered).

## Require

- Melody-forward, fully sung genres. Strong, singable melodic lines.
- Distinct melodic material across a song's sections — sections that share
  too much melody blur together in memory.

## Exclude (genre families)

- Rap / hip-hop — rhythm without melody blends together and resists
  memorization.
- Spoken word.
- Talking blues, or any genre observed to push Suno toward spoken delivery
  (grow this list from listening feedback).

## Observations

- 2026-08-27 — Suno speaks (rather than sings) portions of songs in some
  genres and not others; spoken portions memorize far more slowly. Style
  string guard clauses like "fully sung melodic vocals throughout, no
  spoken word" do **not** measurably reduce spoken delivery — genre choice
  is the effective lever. Which genres trigger it is hard to predict;
  feedback comes from listening.
